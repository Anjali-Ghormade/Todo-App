# Todo App
A modern and responsive Todo App built with HTML, CSS, and JavaScript to help users efficiently manage their daily tasks.

# Features
- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by All, Completed and Pending
- Save tasks using Local Storage
- Fully responsive design
- Empty-state message when there are no tasks

# Tech Stack

- HTML5
- CSS3
- JavaScript
- Local Storage


# Key Learning

Through this project, I practiced:

- DOM Manipulation
- JavaScript Events
- Arrays & Objects
- Local Storage
- Responsive Design
